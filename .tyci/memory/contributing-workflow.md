CONTRIBUTING.md workflow for the-consoomer: pick lowest open milestone via `gh api repos/crazy-goat/the-consoomer/milestones`, list its issues, branch `feature/issue-<N>-<slug>` off main. Tests: `composer test-unit` (fast, no broker), `composer test-e2e-full` (starts RabbitMQ via docker-compose.test.yml), `composer lint` (phpstan+rector+php-cs-fixer). E2E tests use heartbeat=1 + sleep(3) to force a real reconnect path (see HeartbeatTest::testReconnectsAfterHeartbeatTimeout). PR convention: `gh pr create --title "#<N> <title>" --body "Closes #<N>"`; squash-merge only after CI passes AND user approves.

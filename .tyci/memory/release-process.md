the-consoomer release process: main branch is protected (no direct push). CHANGELOG edits go via PR (squash-merge). GitHub Releases created via `gh release create vX.Y.Z --target main --notes-file <file> --latest` (use --latest=false for older versions). Tag must exist on origin before release creation; if the CHANGELOG commit isn't on origin yet, PR-merge first then tag on the merged commit. Conventions: tag = version (vX.Y.Z), release title = tag, notes = the matching CHANGELOG section body. Milestone close: `gh api -X PATCH repos/crazy-goat/the-consoomer/milestones/<N> -f state=closed`. v0.3.0/v0.4.0/v0.5.0 had no releases initially — created retroactively 2026-08-22 alongside v0.6.0.
